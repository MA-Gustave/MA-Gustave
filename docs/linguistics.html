01 / GF Wordbench

A working engineering toolchain.

GF Wordbench is an implemented software workbench for diagnosis, repeatable validation, comparison and release readiness in Grammatical Framework projects. It is not merely an architectural proposal.

The supplied October 2026 snapshot includes source code, test modules, command-line and graphical interfaces, and dedicated GitHub Actions workflows. Its documented pipeline combines source selection, bounded language discovery, static analysis, GF execution, scenarios, regression comparisons and evidence archives.

Important distinction: the presence of tests and CI workflows is verified in the snapshot; this site's audit did not execute the full GF-native suite on every target language. Tool implementation and linguistic certification are different outcomes.

One run evaluates one resolved language context; cross-language portfolio aggregation belongs elsewhere.

02 / Albanian · sqi

A major grammar implementation — and a serious verification program.

The supplied Albanian work is extensive. The snapshot includes hundreds of GF source files spanning morphology, syntax, dictionary, public interfaces and extension modules. It also contains a substantial body of release criteria and linguistic test specifications.

What the evidence actually supports

Implemented work

Grammar and morphological modules, source-level structural/API reconciliation, dictionaries, scenario definitions, tooling and language-specific review records.

Static checks

The supplied C9 report documents 144/144 passing static validations and successful project/scenario contract checks in a staging environment.

Certification design

C10 defines G1: 569 cases, G2: 5,000 cases and G3: 20,000 cases, with generated scenarios and review rules. These are prepared case inventories — not 20,000 claimed passing native GF tests.

Outstanding gates

The available finalization reports explicitly keep exact-source native GF compilation, scenario execution, reviewed gold outputs and expert linguistic sign-off separate. No upstream acceptance is claimed.

Source scope: supplied Albanian snapshot dated October 18, 2026; underlying validation reports dated September 25. The project is substantially implemented but is not presented as linguistically certified on every release gate.

03 / The reference

Compendium is a separate engineering intelligence layer.

The GF RGL AI Compendium organizes grammar contracts, architecture rules, engineering patterns, diagnostics, provenance and review procedures for GF/RGL work.

Its value is reproducible judgment about what a grammar change means, what it can break and how to examine the evidence. It is not an autonomous grammar generator or a runtime dependency of Wordbench.
